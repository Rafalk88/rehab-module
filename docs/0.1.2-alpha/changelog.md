# Changelog – Version 0.1.2-alpha

## What's New

- **Audit Log module added**  
  Tracks all user and system-level actions with timestamps and targets.

- **User Configuration system**  
  Users can now store and update personal settings (e.g., theme, language).

- **Permissions system overhaul**  
  Granular permission system with assignable permission codes.

- **Database schema finalized**  
  Core tables and relationships have been defined.  
  👉 See [Database Documentation](./database.md)

- **Architecture overview added**  
  Describes system layering, module separation, and DB dependencies.  
  👉 See [Architecture Documentation](./architecture.md)

> *Note:* Version 0.1.2-alpha brings more flexibility to the system with audit logs and extended user configurations.
