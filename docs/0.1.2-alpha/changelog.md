# Changelog – Version 0.1.2-alpha

## [0.1.2-alpha] – 2025-04-17

### Added
- **Audit Log:**
  - New audit logging feature introduced to track user actions and changes in the system.
  - Link to [Audit Log Documentation](./audit-log.md) for details.
  
- **User Configuration Enhancements:**
  - Extended user configuration settings for more personalized preferences.
  - Link to the [User Configurations Documentation](./user-configurations.md) for setup and options.

- **Permissions System:**
  - Expanded permissions system to allow granular control over actions (view, edit, delete).
  - Role-based permissions now applied to more system features.

### Changed
- **Database Schema:**
  - Refined relationships between users, roles, and permissions.
  - Updated `user_configurations` table with more detailed settings.

### Fixed
- Minor improvements in user roles handling.
- Fixed UI issues related to dynamic form rendering.
  
---

> *Note:* Version 0.1.2-alpha brings more flexibility to the system with audit logs and extended user configurations.
